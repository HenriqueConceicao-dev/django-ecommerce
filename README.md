# Django E-commerce

E-commerce web application built with Python and Django as a practical backend development project.

## Project Status

🚧 Currently under development.

The project is being developed incrementally while studying and applying Django concepts in practice. New features and improvements will be documented throughout its development.

## Current Features

- Initial Django project configuration
- Store application structure
- URL routing separated between project and store application
- Initial pages for home, store, cart, checkout, account, and login
- Shared base template using Django template inheritance
- Static files configuration
- Initial CSS integration
- Reusable navigation template included in the base layout

## Technologies

- Python
- Django
- SQLite
